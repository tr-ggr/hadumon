# HaduMon creature art provenance

All generated species art used the built-in Imagegen workflow with this shared brief:

> Use case: stylized-concept. Create one full-body feline elemental creature as a premium soft 3D collectible figurine based on a tuxedo cat. Preserve a black cap and ears, white facial blaze and chest, loaf-like softness, and a mildly unimpressed expression. Use a genuinely transparent background, isolated subject, centered square composition, matte plush/vinyl toy rendering, and no text, frame, watermark, pixel art, human traits, or recognizable existing game character design.

Each species then received a species-specific line describing its element, rarity, pose, silhouette, costume, aura, and flavor text. The 24 original renders are stored as optimized WebP files named by stable species ID.

`aurelynx.webp` is a derived fallback made from the Arcpurr render (horizontal flip plus a gold/blue color treatment) because the Imagegen session quota was exhausted on the final legendary slot. `mascot.webp` is a derived crop from the Flameclaw render for the same reason. These files are intentionally marked so they can be replaced with dedicated generation results later without changing any route or type.
